❤️ Connect Apple Health
1 · Workouts → Apple Health, heart rate → here (one shortcut)
When you rate a cardio session, the app automatically runs a shortcut named Log Gym Cardio. It logs the workout to Health, grabs your Watch's average heart rate, and sends it back so the next workout adapts to it. Build it once:
  1. Shortcuts → ＋ new shortcut → rename it exactly Log Gym Cardio
  2. Add Get Dictionary from Input (input = Shortcut Input)
  3. Add Log Workout → Type: High Intensity Interval Training → Duration: Dictionary key minutes (unit: minutes)
  4. Add Find Health Samples → type Heart Rate → filter: Start Date is in the last 1 hour
  5. Add Calculate Statistics → Average of Health Samples
  6. Add Get Contents of URL → the URL below · Method POST · Request Body JSON:
    kind: health
    avghr: (Calculate Statistics result)
    machine: (Dictionary · machine)
    date: (Dictionary · date)
  7. First run asks to read + write Health — allow both. Wear your Watch during the workout so it's recording heart rate.
2 · Pull VO₂ max ← Apple Health
A second shortcut sends your Apple Watch VO₂ max here automatically:
  1. Open Shortcuts → ＋ new shortcut
  2. Add action Find Health Samples → type VO₂ Max, sort Latest, limit 1
  3. Add action Get Contents of URL → paste the URL below · Method POST · Request Body JSON:
    kind: health
    vo2value: (Health Samples value)
    vo2date: (Health Samples start date, format yyyy-MM-dd)
  4. Automation tab → ＋ → Time of Day → weekly → run this shortcut
